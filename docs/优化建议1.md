## 3. 修改建议（逐项）

### U1 触屏操作条（P0）

- **改法**：在 `ImageCard.vue` 用 `useIsMobile()`（已有 `web/src/utils/responsive.ts`）让操作条**常显**；或改为卡片右下角一个 `⋯` 下拉菜单（更省空间）。CSS 侧用 `@media (hover: none)` 兜底，保证触屏设备永远可见。
- **验收**：820px 宽度下每张卡片都能直接点到 下载/直链/MD/删除，无需 hover。

### U2 主题层收敛（P0）

- **改法**：
  1. 保留一份 `:root` tokens（颜色/圆角/阴影/间距/字体）；
  2. 只留**一层** Element Plus 变量覆盖（`--el-color-*` / `--el-text-color-*` / `--el-border-*`）；
  3. 组件级覆盖只针对 EP 没暴露变量的地方（分页组合类、输入框下边线等）；
  4. 删除历史层与已被覆盖的死规则，`!important` 只保留"压 EP 组合类"的必要处。
- **注意**：见第 6 节的四个坑，尤其是**组合类优先级**与 **`!important` 互压**。
- **验收**：`Select-String main.css -Pattern '!important'` 数量显著下降；任意控件都跟随 tokens，不需要再叠层。

### U3 页面结构抽取（P1，配合 U2）

- 抽 `PageCard`（标题+工具栏+空状态+loading）、`DataTable`（列定义+固定列开关+分页）、`usePager`（page/size/total/查询参数同步 URL）。
- **收益**：分页/空状态/移动端行为一处定义，六个页面自动一致。

### U4/U6/U7 体验收口（P1）

- 手机端表格在 ≤640px 改为**卡片列表**（`el-table` 与卡片列表按断点切换，数据同源）；
- 统一空状态组件（图 + 主文案 + 一个主操作按钮）、列表首屏加骨架屏；
- 弹窗统一 `max-height: 86vh` + body 内部滚动。

### U5 无障碍（P1，S）

- 补 `:focus-visible` 样式（延续日系风格：`0 0 0 2px rgba(100,181,246,.35)`）；
- 图标按钮补 `aria-label`；`el-image` 补 `alt`；确认对比度（正文 ≥ 4.5:1）。

### F1 缩略图缓存上限（P0，S）

- 加 `app.thumb.cache-max-size`（默认 2GB）与 `app.thumb.cache-days`（默认 30）；
- 清理策略：写入后异步检查总量，超限按 `lastAccess` LRU 删除；设置页加"清空缩略图缓存"按钮与占用显示。

### F2 审计日志保留与导出（P0，S）

- `app.audit.retention-days`（默认 180）：启动 + 每日清理；`GET /api/audit-logs/export?format=csv` 流式导出。

### F3 元数据导出/恢复（P1，强烈建议）

- 导出：`GET /api/images/export?format=csv|json` 流式输出（objectKey / url / size / hash / width / height / storageType / createdAt / deleted）；
- 恢复：`POST /api/images/import-manifest` 按 `objectKey+hash` 去重回灌（不动云端文件，只补库记录）；
- 可挂到 `/actuator` 之外的定时任务，导出到 `logs/backup/`。

### F4~F8（P2，按需）

- 图库筛选：加 大小区间 / 上传日期区间 / 宽高 / 目录多选；
- 迁移：失败项持久化 + 一键重试 + 断点续跑；导入：按 `lastModified` 增量；
- 分享：`/api/shares/{id}/download` 打包下载 + 访问明细表；
- 重复图片：保留策略（最早/最新/最大）+ 按后端/目录筛选；
- 存储巡检：定时 `test()` 全部启用的配置，失败写审计 + 概览提示；

## 5. 回归与验证约定（沿用本项目既有做法）

- 后端测试：`cd server && ./mvnw test`（当前 56 项，新增功能需同步补用例；集成测试走 H2，不依赖 MySQL）
- 打包：`./mvnw -B -DskipTests -Pwith-web package`（前端产物打进 jar）
- 启动：`./start.cmd`（实现在 `scripts/start-services.ps1`；JVM 参数可用 `config/local.env` 的 `JAVA_OPTS` 覆盖）
- 前端：`npm run typecheck && npm run build`；`index.html` 已设 `no-store`，更新后硬刷新即可
- 真机脚本约定：
  - 业务错误是 **HTTP 200 + body.code**（只有 Spring Security 拒绝才是真 403/401）
  - PowerShell 内联 JSON 会被引号转义搞坏，**一律用文件方式提交**（`--data-binary @file`）
  - 断言单条结果要包 `@(...)` 再取 `.Count`  - **测试数据必须打标记、只清理自己造的**：相册/图片标题带可识别前缀（如 `E2E-`），
    清理时按前缀过滤。`[System.IO.Compression.ZipFile]` 需要先 `Add-Type -AssemblyName System.IO.Compression.FileSystem`
  - ⚠️ **踩过一次**：调试脚本曾用“清理所有分享”而误删了用户自己的两条分享（审计日志里可查 `SHARE_DELETE`）。
    任何带“全部”语义的清理动作，都要先确认范围只覆盖测试数据
- **编码红线**：`scripts/*.ps1`（含 `scripts/start-services.ps1`）必须保持 **UTF-8 BOM**（PowerShell 5.1 无 BOM 会按 GBK 读，中文注释会让脚本语法报错）

## 6. 本轮踩过的坑（改主题时务必注意）

1. **EP 组合类优先级更高**：`.el-pagination .el-pager li` 压不过 `.el-pagination.is-background .el-pager li` —— 覆盖必须写全组合类。
2. **`!important` 互压**：`.el-button--primary` 的 `!important` 底色会盖掉 `.is-link` 的透明底，出现"底色=字色、文字看不见"。
3. **中文不要用 300/200 字重**：中文没有这些字重，浏览器会**合成细体**，笔画发虚、锯齿明显；正文 400、标题 600 最稳。
4. **半像素位移会让文字发虚**：`translateY(-0.5px)` 会让文字落在非整数像素上被重新栅格化。
5. **玻璃态要清干净**：`backdrop-filter` 残留会和"无阴影"的规范冲突。
6. **组件 scoped 样式需要 `!important` 才能被全局层覆盖**（带属性选择器的 scoped 规则优先级更高）。
7. **换主题后必须扫一遍硬编码值**：本轮扫出 **23 处** 白底/细边框/渐变（`background: #fff`、`border: 1px solid`、`linear-gradient`），否则会出现"某块底色不统一"的错位。
8. **字体栈缺失会退化成宋体**：小字号锯齿严重，必须显式声明中文无衬线字体栈。
